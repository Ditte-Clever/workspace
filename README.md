# workspace
Personligt arbejdsrepo til CRM- og Power Platform-arbejde.

| Mappe | Indhold |
|---|---|
| `.github/` | Copilot-instruktioner og genbrugelige prompts |
| `docs/` | Noter og dokumentation |
| `flows/` | Flow-definitioner til fejlsøgning |
| `pbi/` | PBI-skabelon og udkast |
| `PowerPoint/` | PowerPoints og Clevers PowerPoint skabelon |
| `AzureViden/` | Azure-præsentation og konkretiseret Azure-dokumentation |

Regler: Ingen persondata, secrets, adgangskoder eller miljø-URL'er.
